GitHub Repository Analyzer

A simple tool that allows you to explore GitHub repositories and discover detailed information about projects.

💡 Project Idea

The idea is simple:

1. Enter your GitHub username.
2. Explore your GitHub repositories and projects.
3. Choose a repository you want to learn more about.
4. Click Advanced Analysis to get a deeper look at the repository and explore additional information.

Instead of manually browsing through GitHub pages, this tool brings useful repository information together in one place.

✨ Features

- Repository information and descriptions.
- Programming language detection.
- Stars, forks, watchers, and open issues.
- Repository topics and license information.
- Repository creation, update, and last push dates.
- Owner information and GitHub profile links.
- Repository followers and following information.
- Public Gists and their file details.
- Forked repositories.
- Issue events and activity details.
- Repository events and commit information.
- Advanced repository analysis.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub REST API
- Fetch API
- Promises
- DOM Manipulation

🚀 How to Use

1. Open the project.
2. Enter your GitHub username.
3. Select the repository you want to explore.
4. Browse its available information.
5. Click Advanced Analysis to explore deeper repository details.

🔗 API

This project uses the GitHub REST API to retrieve public repository and user information.

Official documentation:

https://docs.github.com/en/rest

⚠️ Notes

- The project relies on GitHub API availability and rate limits.
- Some information may not be available for every repository.
- Advanced analysis may require multiple API requests.
- This project is still under development, and improvements may be added in future updates.

🎯 Project Goal

The goal of this project is to practice JavaScript through a practical application, improve API integration skills, and make exploring GitHub repositories easier.
